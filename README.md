# Objectifs

À la fin de cet atelier, vous saurez :

- Installer Python sous Windows 10/11
- Exécuter un programme Python
- Comprendre un script graphique
- Modifier un projet existant
- Créer une animation temps réel
- Générer un exécutable Windows (.exe)

---

# Étape 1 - Installer Python

## Télécharger Python

Télécharger Python depuis :

https://www.python.org/downloads/

## Installer Python

Lors de l'installation :

✅ Cocher impérativement :

```text
Add Python to PATH
```

Puis cliquer sur :

```text
Install Now
```

---

# Étape 2 - Vérifier l'installation

Ouvrir :

- Invite de commandes (CMD)
- ou PowerShell

Puis exécuter :

```cmd
python --version
```

Résultat attendu :

```text
Python 3.x.x
```
